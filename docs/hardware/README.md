# Разведка железа Aurora S2L (Фаза 0)

Заполняется ДО замены штатной ОС. После `dd` вернуть эти сведения будет неоткуда.

## Чек-лист

- [ ] Полный образ штатного диска снят и проверен на читаемость
- [ ] `lscpu`, `lspci -nnk`, `lsusb -t -v`, `dmesg` сохранены в этот каталог
- [ ] Определено, чем является весовая плата (USB-serial / внутренний UART / что-то иное)
- [ ] Перехвачен обмен штатного ПО с весовой платой (`usbmon` + Wireshark или `interceptty`)
- [ ] Определён командный набор принтера (TSPL / TSPL2 / ESC-POS)
- [ ] Проверено, что сканер ШК — HID-клавиатура (тогда читаем через `evdev`)
- [ ] Тачскрин: производитель, нужна ли калибровка, работает ли под Wayland
