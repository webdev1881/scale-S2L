# Данные каталога

- Поиск товаров по названию фильтруется в Python, а не в SQL: `LIKE` в SQLite не понимает
  регистра кириллицы.
- Товары удаляются мягко (`active = 0`) — на них ссылается журнал операций.
- Миграций пока нет, схема создаётся через `create_all`. При первом изменении моделей на
  устройстве с данными — вводить Alembic.
- В БД от снимка хранится только имя файла (поле `image`); сами файлы, их привязка к
  товарам и подготовка к экрану — в скилле `product-photos`.
- Каталог заливается из выгрузки товароучёта `docs/prod.xlsx` скриптом
  `backend/tools/import_products.py`. Выгрузка лежит в `docs/`, а не рядом со
  снимками: всё, что попадает в `frontend/public/products`, уезжает в сборку и
  раздаётся прибором, а список артикулов с наименованиями там ни к чему. Скрипт: артикул становится кодом товара, единица
  измерения читается из названия («… кг» весовой, «… шт» и «… 200гр» штучные), снимок
  находится по тому же артикулу. Цены и группы в выгрузке нет — ключ `--random-prices`
  ставит заглушку там, где цены ещё нет, а `--groups=` раскладывает группы по первому
  слову названия. Без `--apply` скрипт только показывает план.
