# Данные каталога

- Поиск товаров по названию фильтруется в Python, а не в SQL: `LIKE` в SQLite не понимает
  регистра кириллицы.
- Товары удаляются мягко (`active = 0`) — на них ссылается журнал операций.
- Миграций пока нет, схема создаётся через `create_all`. При первом изменении моделей на
  устройстве с данными — вводить Alembic.
- Фото товаров лежат в `frontend/public/products/`, в БД хранится только имя файла.
  Прибор отдаёт их из собранного фронта, поэтому новый файл появляется на экране только
  после `npm run build` — об этом и о требованиях к снимкам написано в `docs/photos.md`.
  Обложка группы — фото первого товара в ней, отдельного набора картинок нет.
- Набор снимков привязывается к товарам скриптом `backend/tools/link_photos.py`: имя
  файла — код товара (или прежнее имя из поля `image`). Без `--apply` он только
  показывает план. Раскладывать полсотни карточек через админку — работа на вечер.
