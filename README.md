# Aurora S2L

ПО для весов самообслуживания Rongta Aurora S2 с печатью этикеток: Python-бэкенд
и веб-интерфейс (Vue 3 + Element Plus) вместо штатной прошивки.

Прибор: экран 15.6″ 1366×768, НПВ 15 кг с ценой деления 2/5 г, термопринтер
203 dpi с лентой до 56 мм, Intel J6412 (x86_64). Подробности и следствия для
кода — `docs/hardware/aurora-s2.md`.

Целевая платформа — Ubuntu 24.04 LTS x86_64 в режиме киоска. Разработка ведётся
на любой машине: весь доступ к железу спрятан за слоем абстракции, у которого есть
симулятор.

## Из чего состоит

| Каталог | Что внутри |
| --- | --- |
| `backend/` | FastAPI, SQLite, драйверы железа (`app/hal/`), рендер этикеток |
| `frontend/` | Vue 3 + Element Plus: киоск (покупатель) и админка (оператор) |
| `deploy/` | systemd-юниты, udev-правила для развёртывания на устройстве |
| `docs/hardware/` | Паспорт прибора и результаты разведки железа (Фаза 0) |

## Быстрый старт (без весов)

```bash
# 1. Бэкенд
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Linux: .venv/bin/python
.venv/Scripts/python -m uvicorn app.main:app --reload --port 8000

# 2. Фронтенд (в отдельном терминале)
cd frontend
npm install
npm run dev
```

- Киоск: http://localhost:5173/
- Админка: http://localhost:5173/admin.html
- OpenAPI: http://localhost:8000/docs

Каталог заполняется демо-товарами при первом запуске. Интерфейс и этикетка —
украинские; язык переключается в админке (**Налаштування → Мова інтерфейсу**) и влияет
сразу на киоск, админку и печать.

Каталог в киоске двухуровневый: сначала карточки групп, внутри — карточки товаров
с фотографиями. Демонстрационные снимки лежат в `frontend/public/products/`
(источники и лицензии — в `credits.md` рядом с ними); в базе хранится только имя файла,
и его можно поменять в админке.

### Как «положить товар на весы»

Админка → **Симулятор**: ползунок задаёт массу на платформе, тумблеры имитируют отказы
принтера. Вес приходит в киоск по WebSocket так же, как придёт с реальной платы.

## Сборка для устройства

```bash
cd frontend && npm run build     # собранный фронт отдаёт сам FastAPI
cd ../backend && .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Тогда киоск открывается на `/`, админка — на `/admin`. Отдельный nginx не нужен.

## Переключение на реальное железо

В `backend/.env`:

```ini
S2L_HAL_BACKEND=real
S2L_SCALE_PORT=/dev/s2l-scale
S2L_PRINTER_DEVICE=/dev/s2l-printer
```

Больше нигде в коде правок не требуется — реализации выбираются в
`app/hal/registry.py`. Конкретный кадр протокола весовой платы подтверждается
на Фазе 0 и правится в одной функции `_parse_frame`.

## Метрология

Замена штатной ОС снимает весы с поверки. Для разработки и внутреннего учёта это
не имеет значения; для применения в торговле потребуется отдельно решать вопрос
сертификации ПО (ДСТУ OIML R76, WELMEC 7.2) — с разделением юридически значимой
и незначимой частей.
